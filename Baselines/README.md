| *Can Language Models Teach Weaker Agents? Teacher Explanations Improve Students via Personalization* [Saha et al., 2023] | Intervention, ToM | This study proposes a teacher–student framework where a teacher LLM selectively intervenes with natural language explanations to improve a weaker student LLM’s reasoning. It evaluates whether the intervention by the bigger model can enable the lower model to make more accurate predictions. The authors also note that each intervention incurs a communication cost—an intervention budget. They pose five research questions (RQs): (1) Can a teacher LLM intervene at test time to improve a student LLM's prediction? (2) When should a teacher intervene? (3) Given a set of data interventions, can a teacher personalize its explanation for a student (ToM)? (4) In multi-turn interactions, do teacher explanations generalize and improve student performance across data points? (5) Can misguided teachers lower student performance? | RQ1: Larger Teacher LLMs significantly improve smaller student performance through explanatory interventions at test time. More interventions leads to better Performance. RQ2: The Expected Utility Intervention Function allows teachers to choose the most beneficial intervention points, balancing accuracy and communication cost. RQ3: Personalized ToM-inspired explanations yield modest but consistent performance gains. RQ4: Teacher explanations generalize beyond the explained samples, improving future performance in multi-turn settings. RQ5: Misaligned teachers can reduce student performance, showing LLMs’ sensitivity to explanation quality. | RQ1: Can teacher LLM improve student by intervening.
